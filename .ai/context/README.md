# context/

This directory stores the active project context and the team's **context-skills**.

## Structure

```
context/
├── README.md               ← this file
├── project-context.md      ← generated by `install-ai-package.sh --scan` (specific to the target repo)
└── skills/                 ← context-skills; the agent absorbs them automatically without invocation
    ├── hexagonal-architecture.md
    ├── testing-java.md
    ├── observability.md
    ├── reactive-programming.md
    ├── error-translation.md
    └── domain-modeling.md
```

## What is `project-context.md`?

It contains the architecture, stack, and conventions **specific to the target repo**. It is generated
when installing the package (via `--scan`) and is not part of this starter kit's own content.

## What are context-skills?

Distillations of real, hard-won experience turned into concrete and actionable patterns.
Unlike callable skills (`<AI_ROOT>/skills/`), **they do not require explicit invocation**:
the agent reads them as part of the session context and applies their guidelines automatically.

Each context-skill answers:
- **What the pattern is** and why it exists
- **How to apply it** in your projects
- **Minimal abstract canonical example**
- **Common mistakes** to avoid

The skills shipped here default to a **Java/Spring/Maven profile**. If your project uses a different
stack, adapt or replace these files following the same structure — see the root `README.md` for guidance.
